## 🚀 Featured Projects

### EVision — AI-Powered EV Predictive Maintenance

A collaborative ML and software engineering project exploring EV fault diagnosis and predictive maintenance.

- Preserves dataset exploration, preprocessing, model evaluation, and negative findings from an earlier weak-signal dataset.
- Classifies normalized sensor observations as **Normal, Motor Fault, Inverter Fault, or Battery Fault**.
- Integrates a saved Random Forest pipeline with FastAPI, manual prediction, validated CSV uploads, and interactive analytics.
- My focus: backend development, prediction workflows, model integration, validation, testing, and frontend/backend integration. Developed with **Tejaswini Barhate**, whose work focuses on data research and preparation.

**Recorded supplied-test results:** 99.42% accuracy and 99.21% macro F1 on 3,300 observations. The dataset has unusually easy class boundaries, unknown original normalization parameters, and no timestamps or vehicle IDs. These scores do **not** establish real-world fleet, Tesla, temporal, or cross-vehicle performance. RUL and risk modules remain unavailable.

**Stack:** Python · pandas · scikit-learn · FastAPI · HTML/CSS/JavaScript  
**[Explore the repository →](https://github.com/AaryaWaghmare7/Predictive-Maintenance-ML)**

### SecureLens — Image Authenticity & Fraud Detection

An image-forensics application exploring AI-generated and manipulated images through **forensic heuristic analysis**.

- ELA, FFT-based frequency analysis, image statistics, and JPEG compression experiments.
- Upload, batch analysis, comparison, and downloadable report workflows.
- Python analysis integrated with a FastAPI backend and web interface.

Heuristic outputs are **not trained-model probabilities or definitive proof** that an image is fake, manipulated, or authentic. A validated classifier is not currently connected.

**Stack:** Python · OpenCV · Pillow · NumPy · FastAPI · React/Vite · PostgreSQL  
**[Explore the repository →](https://github.com/AaryaWaghmare7/SECURELENS)**
